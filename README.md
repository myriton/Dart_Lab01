Узнали: Основные типы Dart, строковую интерполяцию, разницу между final и const, Null Safety, коллекции, объявление функций

Ответы на вопросы:
1. Dart: Статическая типизация, тип переменной известен на этапе компиляции. Sound Null Safety — компилятор не даст получить ошибку при работе с null. Python: динамическая типизация, тип определяется во время выполнения. Преимущество заключается в том, что ошибки компилятор поймает заранее, а не в рантайме.
2. String?? - означает, что если null, то использовать <значение>(т.е можно задать значение, а не выводить просто null) . String? — nullable-тип, переменная может содержать null(т.е <?> используется для разрешения null)
3. final — значение присваивается один раз, но может быть вычислено во время выполнения программы. final защищает от случайной перезаписи
4. Именованный параметр передаётся по имени и required — параметр обязателен, без него ошибка компиляции (Пример: describePet(name: 'Барсик')), а позиционный — строго в том порядке, в котором параметры объявлены (Пример: greet('Артём'))
